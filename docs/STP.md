# STP - Software Test Plan

## Scope
High-level manual QA for core user flows of the AllTrails demo site.

## Objectives
- Validate core features end to end  
- Run sanity then regression cycles  
- Document results and defects clearly  

## Test Levels
Sanity, Regression, Exploratory

## Environment
Desktop and mobile web (Chrome, Edge)

## Risks & Assumptions
Cross-browser differences, latency, or missing validations.

## Entry / Exit Criteria
- Entry: build is stable, data is ready  
- Exit: all sanity passed, no critical open bugs
