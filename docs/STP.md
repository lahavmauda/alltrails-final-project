# STP - Software Test Plan

## Scope
High level manual QA for core user flows of the AllTrails demo site.

## Objectives
- Validate critical paths end to end
- Run sanity then targeted regression
- Log defects with clear evidence

## Test Levels
Sanity, targeted regression.

## Environments
Desktop web and mobile web views.

## Risks and Assumptions
Cross browser differences, network latency, missing client side validations.

## Entry Criteria
Stable build, basic data ready, user stories defined.

## Exit Criteria
Sanity pass, no open critical defects, all known issues listed in Issues.
