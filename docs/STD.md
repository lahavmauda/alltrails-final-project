# STD - Test Design

## Coverage Map
- Authentication
- Search
- Navigation
- Account

## Test Conditions
- Login: valid, invalid, edge inputs
- Search: keyword, filters, empty query
- Navigation: header, footer, deep links
- Account: profile view and edits

## Entry and Exit Criteria
Entry: app reachable, test data ready  
Exit: all listed conditions executed, defects reported with repro steps.

## Notes
Full cases can be managed in Issues using the Test case template.
